# Project documentation

[`TCC-Pantry-Project-Overview.pdf`](./TCC-Pantry-Project-Overview.pdf) — a 6-page overview of the
app: product tour with screenshots, architecture, data model, the offline-sync engine, the HTTP
API, and the tech stack.

## Screenshots

The Flutter SDK / a browser for the live app are not available in the documentation build
environment, so the screenshots are **high-fidelity HTML mockups** rendered with Chromium. They use
the app's real design tokens — the coral `#FF5A33` brand colour, the Plus Jakarta Sans / Inter font
pairing (embedded from `app/assets/fonts`), the 3-column snack grid, and the frosted-glass bottom
nav. They faithfully represent the real screens but are reconstructions, not device captures. To use
real captures instead, drop PNGs into `build/shots/` (named `onboarding|food|drinks|cart|orders|admin.png`)
and rebuild.

## Rebuilding the PDF

Requires Node with Playwright's Chromium available.

```bash
cd docs/build
python3 -c "import base64,pathlib; \
  c=lambda p: base64.b64encode(pathlib.Path(p).read_bytes()).decode(); \
  pathlib.Path('assets.css').write_text(\"@font-face{font-family:'Jakarta';src:url(data:font/ttf;base64,\"+c('../../app/assets/fonts/PlusJakartaSans.ttf')+\") format('truetype');font-weight:200 800;}@font-face{font-family:'Inter';src:url(data:font/ttf;base64,\"+c('../../app/assets/fonts/Inter.ttf')+\") format('truetype');font-weight:100 900;}\"); \
  pathlib.Path('logo.txt').write_text('data:image/png;base64,'+c('../../app/assets/brand/pantry_logo.png'))"

node screens.js   # build the per-screen HTML mockups
node render.js    # capture them to build/shots/*.png
node doc.js       # assemble the document HTML
node topdf.js     # render docs/TCC-Pantry-Project-Overview.pdf
```
